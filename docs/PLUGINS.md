# zWeb · Плагины

Плагин — это один JavaScript-файл. Он расширяет zWeb: добавляет пункты, реагирует на
события, отправляет и читает сообщения — но только то, что вы ему разрешили.

## Быстрый старт

Сохраните файл `hello.plugin` (расширение может быть любым, читается текст):

```js
/**
 * @name        Приветствие
 * @id          hello
 * @version     1.0.0
 * @author      @frizovdanya
 * @description Здоровается при запуске
 */

module.exports = {
  onLoad(api) {
    api.ui.toast('Привет от плагина zWeb!');
  },
  onUnload() {}
};
```

**Настройки → zWeb → Плагины → Из файла** — и плагин установлен.

## Шапка плагина

Перед кодом идёт комментарий с тегами:

| Тег | Обязателен | Что значит |
|---|---|---|
| `@name` | да | Название в списке |
| `@id` | нет | Уникальный идентификатор (латиница, дефисы); по умолчанию — из названия |
| `@version` | нет | Версия, показывается рядом с названием |
| `@author` | нет | Автор |
| `@description` | нет | Описание под названием |
| `@permissions` | нет | Запрашиваемые права через запятую |

## Права

Плагин ничего не получает по умолчанию. Каждое право включается галочкой в карточке
плагина, и без него вызов падает с ошибкой (а в журнал попадает строка «отклонено»).

| Право | Что открывает |
|---|---|
| `network` | `api.network.fetch` — запросы в интернет |
| `files` | `api.files.save` — сохранение файлов |
| `messages.read` | `api.messages.onNew` — новые сообщения |
| `messages.send` | `api.messages.send`, `api.messages.delete` |
| `intents` | `api.intents.open` — открытие ссылок |
| `settings` | доступ к настройкам приложения (зарезервировано) |

## API

```js
module.exports = {
  async onLoad(api) {
    // кто я
    api.pluginId;         // 'hello'
    api.permissions;      // ['network', ...]
    api.has('network');   // true/false

    // свои настройки (переживают перезагрузку)
    api.settings.set('theme', 'dark');
    api.settings.get('theme');   // 'dark'
    api.settings.all();          // {theme: 'dark'}

    // личное хранилище (localStorage с префиксом плагина)
    api.storage.set('counter', '1');
    api.storage.get('counter');  // '1'
    api.storage.remove('counter');

    // интерфейс
    api.ui.toast('Готово');
    const ok = await api.ui.confirm('Удалить всё?', 'Отменить нельзя');

    // сообщения (нужны права)
    await api.messages.send('-1001234567890', 'Привет из плагина');
    await api.messages.delete('-1001234567890', [12345]);
    const off = api.messages.onNew((message) => {
      console.log('новое сообщение', message);
    });

    // сеть
    const response = await api.network.fetch('https://example.com/api');

    // файлы
    api.files.save('data.json', JSON.stringify({ok: true}));

    // ссылки
    api.intents.open('https://t.me/frizovdanya');

    // события приложения Telegram
    const stop = api.on('history_append', ({message}) => { /* ... */ });
  },

  onUnload() {
    // уберите за собой таймеры и подписки (подписки через api.on и
    // api.messages.onNew отписываются автоматически)
  }
};
```

`onLoad` может быть `async`. Всё, что вернул `api.on(...)`, — функция отписки; её полезно
вызывать самому, если подписка больше не нужна.

## Что плагину недоступно

Внутри плагина `window`, `document`, `localStorage` и `fetch` — заглушки: глобального
доступа к приложению нет, иначе разрешения ничего бы не значили. Любое обращение к ним
попадает в журнал.

## Журнал

Блок **Журнал** в разделе плагинов показывает последние 40 записей: загрузку, выгрузку,
ошибки и отклонённые обращения. Кнопка «Очистить журнал» стирает их.

## Безопасный и небезопасный режимы

- **Безопасный режим** — не загружается ни один плагин; приложение запускается всегда,
  даже если какой-то плагин его ломал.
- **Небезопасный режим** — проверки прав выключены, плагин получает всё. Только для
  собственного кода.

## Публикация

Положите файл на любой прямой URL (GitHub raw, ваш сервер) и установите через
**Плагины → По ссылке**. Ссылка на документацию — кнопка **Docs** на том же экране.
